# Experiment 3 — MapReduce Word Count

Java implementation using Hadoop's current `org.apache.hadoop.mapreduce` API, built using Maven. No Eclipse project or manually-added JARs are required.

```bash
./run.sh
```

Requires a working Hadoop pseudo-distributed/single-node setup, Java and Maven. Output path is `/user/$USER/bcs714d-wordcount-output`.
